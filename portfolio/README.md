# Abderrahman Kouki — recruiter portfolio

Bilingual static portfolio with French at `/` and English at `/en/`.

## Edit and build

Edit the content and template in `build.mjs`, then run `node build.mjs` from this directory. The stylesheet is `dist/recruiter.css`; the small disclosure enhancement is `dist/site.js`. No dependencies or API keys are required. Native project and FAQ disclosures also work without JavaScript.

The French CV is `dist/abderrahman-kouki-cv.pdf`; the supplied English CV is `dist/abderrahman-kouki-cv-en.pdf`. Experience copy is grounded in the supplied CVs. The recruiter brief contains editorial answers, not generated AI responses.

## Hosting

The Sites preview uses `.openai/hosting.json`. The GitHub repository deploys `portfolio/dist` through its GitHub Pages workflow to `kouki-abderrahmen.tech`. The previous compiled site remains in the GitHub repository history and original files for reference; it is not the workflow's published directory.
